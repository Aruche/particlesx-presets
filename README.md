ParticlesX preset catalogue
===========================

A searchable showcase of the 218 emitters that ship with the ParticlesX
addon for Construct 3.  Open `index.html`, or the published version on GitHub
Pages; the manual is in `manual/`.

Each card shows the effect, the object type name and the page it lives on in the
preset library, so a preset can be found here and copied from the Construct
project.  Everything on the page is generated from the addon's own preset
specifications, which is why the names and pages cannot drift from the project.

ParticlesX and its preset library are distributed separately; this repository is
only the showcase.
