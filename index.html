ParticlesX Presets - 218 presets

Every effect is a ParticlesX object in the Construct 3 project provided in the same package as this page, along with the ParticlesX addon.

Copy an effect. Filter or search below, then note the object name and the cell it sits in: Presets 2, cell 3,2 is column 3, row 2 of that layout, counting from its top-left. Open that layout in ParticlesXPresets and copy the object into your own project.
Or browse in the editor. Object types are named after their presets and listed alphabetically in the project bar, so CampfireFlame is under C.

Hover a card to see the effect move; click it to open the full-size loop over this page.
